# Retro cosmetic picker

A separate retro edition with two plain grey buttons: **Skins** and **Avatar**.

- Skins includes Guns and Melees.
- Avatar uses a Roblox user ID, with Apply, Restore, and Unload controls.
- Misc, presets, and individual shirt/pants/hat inputs are removed.
- The menu hotkey hides or reopens the entire interface, including both launcher buttons. Its default is RightShift; a previously saved menu key is respected.
- Close hides the current window. On touch devices, a two-finger tap can reopen a hidden interface.
