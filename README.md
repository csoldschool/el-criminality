# Retro cosmetic picker

A separate retro edition with three plain grey buttons: **Skins**, **Avatar**, and **Misc**.

- Click a button to open its window; click it again or use **Close** to return to the three buttons.
- **Skins** includes Guns and Melees.
- **Misc** contains Presets, color controls, the menu keybind, and Unload.
- The default window toggle key is **RightShift**; change it in Misc.
